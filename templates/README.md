# 画像テンプレートの差し替え方法

このフォルダに以下のファイルを置くと、生成画像の背景として使われます。

| ファイル名 | 用途 |
|---|---|
| `background_open.png` | 開館日の背景(1080×1920px 推奨) |
| `background_closed.png` | 休館日の背景(1080×1920px 推奨) |

ファイルが無い場合は `config.yml` の `image.open.background` / `image.closed.background` の単色背景が使われます。

日付・開館時間などの文字は背景の上に自動で重ねて描画されるため、背景デザインの中央付近(縦 400px〜1400px あたり)は文字が読めるよう余白にしておいてください。
